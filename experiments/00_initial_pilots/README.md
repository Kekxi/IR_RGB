# Early pilots and OAFA context

The `reports/` directory preserves the initial MTDSP baseline, de-duplication, and OAFA comparison notes from 2026-10-16 through 2026-10-18. These runs preceded the final V4 label review and use different data/label protocols. Use them as historical context, not as directly comparable V4 ablations. Their original raw run artifacts and third-party OAFA source are not duplicated in this repository.
