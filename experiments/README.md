# Experiment index

Each numbered directory is a separate training/evaluation stage or matched ablation and contains a README with the compared variants, label coordinate system, primary evidence, and conclusion. Keep the training chain in mind: B2 variants continue from a prior B1 checkpoint; B3 first stage initializes from V4 B1; B3 phase-2 variants all continue from the same B3 checkpoint. Unmatched stages must not be treated as causal module comparisons.
