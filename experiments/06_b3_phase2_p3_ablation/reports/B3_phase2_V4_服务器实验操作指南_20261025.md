# B3 第二阶段：V4 雾天 RGB 辅助 IR 检测实验

## 目的与模型

目标是改善**雾天目标识别**，尤其是 IR 清晰、RGB 模糊的船；“多发现几艘实体船”是后续可选的系统级表述，不作为当前训练是否值得继续的唯一指标。

三组新实验都从**同一个已训练的 B3 第一阶段 `best.pt`** 出发，沿用 V4 图像、双原生标签、seed 42、图像尺寸 960、优化器和训练轮数：

| 变体 | IR 路径的变化 | 用途 |
| --- | --- | --- |
| `control` | 原 B3 结构继续训练 40 轮 | 排除“多训练 40 轮”本身的影响 |
| `direct` | IR P3 接收同位置 RGB 特征的受控残差 | 检查跨模态信息传递是否有用 |
| `local` | IR P3 在周围 9×9 个 RGB 位置匹配，按匹配可信度注入残差 | 检查局部对应能否进一步改善 |

`local` 的搜索半径为 4 个 P3 单元。选择依据只来自 **V4 训练集**的高置信几何对应草稿：5×5 覆盖约 34%，9×9 约 71%。它只是覆盖率估计，并不能证明对应关系逐船正确。匹配不可信时，原生 IR P3 特征仍沿恒等路径进入 IR 颈部/检测头；新增残差初始为零，所以新模型的起点与 B3 完全一致。RGB 融合头、IR 原生头仍分别接受各自标签监督。

## 服务器操作

在登录节点进入代码目录，先检查依赖与路径，然后一次提交三组 GPU 作业：

```bash
cd /work/home/kekexiong/fog_ship_code_20261019
bash server_submit_b3_phase2_v4.sh prepare
bash server_submit_b3_phase2_v4.sh submit all
bash server_submit_b3_phase2_v4.sh status
```

`submit all` 会提交 `control`、`direct`、`local` 三个独立 Slurm 作业。若想分开提交，也可运行 `bash server_submit_b3_phase2_v4.sh submit local` 等命令。默认使用分区 `xhhgnormal02`、单 GPU、batch 2、40 轮；如服务器显存不足，可在**三个作业都未提交前**统一设置 `BATCH=1`，三组保持相同配置。作业日志在代码目录下 `slurm-b3p2_*-<jobid>.out`。

每组作业会自动：训练 → 在全部 877 个配对验证样本上分别计算 RGB/IR 原生指标 → 在 633 个雾天配对样本上分别导出 `predictions.jsonl` 和原生 AP。若训练完成但后处理意外中断，可在有 GPU 的作业环境中运行 `bash server_submit_b3_phase2_v4.sh eval local`，不重训权重。

三组的 `status` 都显示雾天 RGB、IR 指标后，在登录节点运行：

```bash
bash server_submit_b3_phase2_v4.sh compare
```

结果位置：

- 权重：`runs_b3_phase2_v4/b3p2_{control,direct,local}_s42_v4/weights/best.pt`
- 全部验证样本原生指标：`eval_b3_phase2_v4/native_all/<variant>/{rgb,ir}/native_metrics.json`
- 雾天原生指标及预测：`eval_b3_phase2_v4/exports/<variant>/b3_{rgb,ir}/{export_summary.json,predictions.jsonl}`
- 对照报告：`eval_b3_phase2_v4/comparison/comparison.md`，详细数据为同目录的 `comparison.json`

## 怎样判断结果

优先看 **633 对雾天样本**上的 IR 原生 mAP50:95、召回；同时查看 RGB 原生指标，确认改善 IR 时是否损伤 RGB。然后比较相同误报预算下，两头合并的逐图像对目标检出数：`local` 应与 `control`、`direct`、原始 B3、IR-only 和 RGB-only＋IR-only 独立合并比较。`local > control` 才能排除继续训练的影响；`local > direct` 才能支持局部匹配本身的价值。

自动跨模态对应产生两种探索性假设，并非人工核实真值；阈值也在同一验证集上挑选，所以对照报告适合决定下一轮实验。若要在论文中写“整段视频多发现了 N 艘实体船”，需在独立视频事件上做最终评估，并仅复核影响该数字的少数船轨迹。
