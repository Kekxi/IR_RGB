## 三、B0 训练：为什么目标只能是"检测器分数一致性"

原始材料里 **171 条已核实同船、0 条已核实异船**，被接受的背景对只有 2 条。因此：

- 「船 vs 背景」判别目标：负例 2 条，不可训练；
- 「配对可信度」判别目标：负例 0 条，不可训练。

B0 只能取一个不依赖身份标签的目标：

```
teacher(t) = max( conf_rgb(t), conf_ir(t) )      # 只用检测器输出
loss       = BCE( head(R + g·P(A)), teacher )    # 不使用任何门控标签
```

`c_pair`（点一校准同船概率）只作为门控输入，从不作为目标。这回答的是 B0 唯一能回答的问题：**在只有检测器分数的监督下，门控会不会学出内容依赖，还是停在 `g = c_pair` 的恒等解。**

对照运行：A = 全门控可学；B = 门控冻结在初始化（`P(A)=0`、`g = c_pair`），只训统一头。

## 五、结果

| 运行 | dev BCE（3 种子） | h 输出 std | α | dev g 均值 / std |
|---|---|---|---|---|
| A 全门控 | **0.3549 ± 0.0010**（0.3536 / 0.3551 / 0.3560） | 4.24 ± 2.27 | 0.912 | 0.949 / 0.02–0.21 |
| B 门控冻结 | 0.3699 ± 0.0122（0.3871 / 0.3605 / 0.3622） | 0（恒等） | 1.000 | 0.990 / 0.010 |

三个种子逐对比较，A 的最大值 0.3560 仍低于 B 的最小值 0.3605。

细节：

- **首步梯度**：投影 0.0284，门控头 0.0；第二步起 2.7e-05 → 7.1e-05 → 1.1e-04。复现了「零初始化导致门控头第一步无梯度」。
- **拒配**：`g` 置零后融合输出与 R 逐位相等（`reject_equals_R = True`），`g_rej = 0`。
- **统一头**：B 组 `q_fused` 与 `q_rgbonly` 逐位相同（Δ = 0），证明零门控路径没有旁路。
- **弱 / 清晰**：A 组 dev 上 Δweak = +0.142 ± 0.073、Δclear = +0.539 ± 0.061（logit 增量）。弱样本的增量小于清晰样本，因为教师的差异集中在清晰侧。

## 六、可以写的三条

1. **结构三项在本机全部复现，数值与 Mac 记录逐项一致**（跨平台、跨机器）。零残差等价、拒配恒等、统一头唯一、首步零梯度四条都成立。
2. **456 条接受配对可精确复现**，且身份构成与清点表逐项吻合；这条同时验证了 `model_box_relative.json` 与 `geometry_pipeline.py` 的部署一致性。
3. **区域级门控在检测器分数监督下没有塌缩**：h 学到 std 4.2、g 在 dev 上 std 0.13–0.21，而固定门控对照恒为常数；dev BCE 低 0.015，且三种子逐对占优。这与本项目像素级调制的四次塌缩形成对照——差别在监督目标的逐样本方差，不在参数量。

## 七、不能写的三条

1. **不能写"融合提升检测"**：教师是检测器自身分数，不是检测精度；g 均值 0.96 有一部分是 `max(conf_rgb, conf_ir)` 这个目标本身偏向"开"造成的。
2. **不能写"门控学会了何时该信红外"**：171 正 / 0 负，没有抑制示例，门控只能学"往教师靠"，学不到"该拒绝"。
3. **不能把 0.015 BCE 当性能证据**：教师分布只有 0.890–0.951 的宽度，BCE 差值天然被压小；dev 只有 2 个事件 32 对、单次划分、未做事件级区间。

## 八、一个副产品结论（比 B0 本身更有用）

`c_pair` 在接受池上已经是 **0.9926 ± 0.0085**，即常数。也就是说：

> 点一的同船概率在它的工作点附近已经饱和，"置信度先验"这一项在 B0 里几乎不携带信息，门控实际上退化成 `h(pool(R), pool(A))` 单独决定。

这对点二的设计有直接影响：把 `c_pair` 当门控先验，只有在**候选池**（含 0.02–0.07 的临界区间）上才有区分度，在接受池上没有。若后续用 B0 的权重做 B1，需要重新在对数几率尺度上检查 `alpha·logit(c_pair)` 的方差贡献。

## 九、下一步

1. **补抑制负例**：按 `点二样本清点` 的建议，在 0.10 / 0.13 更低工作点收集被接受的异船对，或从同帧邻船取红外块替换（后者须标注为合成）。这是 B1 的解锁条件。
2. **换教师**：把 `max(conf_rgb, conf_ir)` 换成"两侧一致的船体证据"（例如两侧框内响应的一致性），避免目标本身偏向开门控。
3. **dev 扩大**：把 9 个事件做 leave-one-event-out，而不是固定 2 个事件，给出事件级区间。
4. **进检测损失联合训练**：需要把门控插进检测器（`Detect` 输入前），只在 GPU 上做；当前标签不支持负例，先不做。
