# MTDSP 雾/低能见度船舶检测实验起点（2026-10-19）

## 研究问题

在 RGB 因雾或低能见度导致船舶对比度下降时，利用 IR 保留可辨认的船舶特征，同时抑制错位区域和失真模态对检测的干扰。主要检测指标以固定 RGB 坐标系的船舶真值为准。另将“IR 有船、RGB 同视场无标签框”的目标作为独立研究问题，不混入现有 RGB mAP。

## 固定数据与当前证据

- 使用只读数据版本：E:\HEU_4151\RGB_IR\MTDSP_v2_final_20261019\dataset。哈希与计数见同级 freeze_summary.json 和 file_hashes.csv。
- 按采集事件划分的原 train/val 为 1267/878 对；两对尺寸不同，现有融合加载器固定排除，融合口径为 1266/877。单模态和融合做直接比较时，也使用同一图像 ID 集合。
- 用户已确认标签无误。33 对逐船记录含 132 个 IR 框；其中 20 个是“共同视场、RGB 无对应框”的候选（train 15、val 5）。现有 RGB 真值无法把这些目标计为正确检出。
- 100 对诊断抽样中，78 对人工填 haze_fog；验证部分仅 49 对，其中 41 对 haze_fog、8 对 clear，均为 day。此小样本用于查看现象和调试，不作为正式条件 mAP 的主样本。haze_fog 是图像视觉判断，不是气象仪器记录。

## 先做可比较的基线

1. 用最终标签和统一排除清单，对现有 RGB-only、IR-only、双骨干 P3/P4/P5 Concat+1×1 Fusion、OAFA 的旧 best.pt 做一次固定权重重评估。这是快速检查，不替代正式重新训练。
2. 正式比较时从相同初始化和种子重新训练。最终版训练标签涉及 RGB 与 IR 改动，旧权重的历史成绩不能当作同一标签版本下的公平对照。固定输入尺寸、数据划分、增强、优化器、训练轮次/早停规则；至少记录三个种子与模型选择规则。
3. 统一输出 full-val AP50、AP50–95、Recall、推理速度/显存。主表使用同一 877 对融合可用图像；另单独报告单模态在自身 878 对上的结果，避免混用分母。

## 雾天评价组先完善

给全部验证图像增加只读的图像级条件表，至少包含 image_id、event、visibility（clear / haze_fog / low_visibility_unknown）、illumination、reviewer。优先检查同一事件内是否发生天气变化，不能仅由时间戳或事件 ID 自动赋值。固定表之后统计各组图像数和船舶实例数，再计算条件 AP。事件内相邻帧相关，误差区间按事件重抽样，不把帧当成独立样本。现有验证集在训练时用于模型选择；投稿级泛化结论还需独立事件测试或外部数据。

## 第一版改进与消融

以现有双骨干 Fusion 为母体，仅增加一个局部可靠性门控：从 RGB 局部对比度/纹理、IR 局部响应，以及跨模态特征一致性估计每个空间位置和尺度的权重。雾中 RGB 可靠性低时提高 IR 特征贡献；IR 失真或错位时降低其贡献。先不额外叠加图像重建、小波等模块。

- B0：现有 Fusion。
- B1：B0 + RGB/IR 可靠性门控。
- B2：B0 + 小范围局部对齐或可学习偏移。
- B3：B0 + 对齐可信度调节的可靠性门控。
- B4：B0 + 与 B3 相同的 RGB 雾化增强，但不加新模块；B3 也使用同一增强。这样才能区分模块收益与数据增强收益。

主指标是人工标记低能见度组的 AP50–95 和 Recall；同时报告 clear 组和全量结果，防止雾天提升来自清晰场景显著退化。对 RGB 有标签但视觉弱的船舶，另做逐目标召回分析；现有验证抽样中仅约 14 个对应 G 框的例子，需扩大后才能形成稳定结论。对 IR 同视场而 RGB 无框的目标，必须先建立共同视场的目标真值和坐标评价规则，不能直接把模型在这些位置的预测当作 TP。

## 弱配准压力测试

在同一验证图像上只对 IR 支路施加预先固定的平移/尺度扰动，RGB 图像和 RGB 真值不动。至少含原始、轻、中、重三个等级；记录扰动的像素尺度、随机种子及越界处理。比较 B0、B2、B3 的性能曲线。此测试证明的是受控错位鲁棒性，不代表真实海况配准误差分布。

## 开始顺序

A. 固定最终数据版本与同一图像 ID 集合（已完成）。
B. 完成旧权重重评估与全验证集条件表。
C. 重训 B0 及三组公平基线。
D. 实现 B1，先跑小规模消融；若雾组没有稳定收益，先检查可靠性权重和失败案例，再决定是否增加 B2/B3。
E. 在独立事件或外部数据上验证后，才写正式的雾天泛化结论。
